GitHub access

Replace writes the Word file to the portal's GitHub repository. It needs a fine-grained personal access token, kept in this browser only.

  1. Open github.com → Settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → ienergy-portal.
  3. Permissions: Contents: Read and write. Add Actions: Read and write to deploy to the live site from here.
  4. Generate, copy the token and paste it below.

Replace on portal

The old file stays in GitHub's history, so a replace can always be undone.
